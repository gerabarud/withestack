# 🎬 Sesión de Práctica Interactiva

## Bienvenida a tu Sesión de Estudio

Aquí te guiaré a través de ejercicios prácticos mientras explicas lo que sucede.

## 📝 OPCIÓN 1: Comienza con Linux Fundamentals

¿Quieres practicar en terminal? Tenemos varias opciones:

### A. Crear estructura de usuarios (15 min)
```
- Crear grupo "sysadmins"
- Crear usuario "admin1" en ese grupo
- Dar permisos específicos
- Verificar configuración
```

### B. Configurar networking (20 min)
```
- Ver interfaces de red actuales
- Entender configuración de netplan
- Crear configuración IP estática
- Aplicar cambios
```

### C. Practicar scripting Bash (25 min)
```
- Crear script que monitore CPU/RAM
- Ejecutar y ver resultados
- Agregar a cron
```

### D. Docker (20 min)
```
- Ejecutar contenedor Nginx
- Exponer puertos
- Acceder desde navegador
```

## 🎯 OPCIÓN 2: Quiz de Autoevaluación

Responde estas 10 preguntas rápidas para saber en qué nivel estás:

1. ¿Qué comando creas un usuario con home?
2. ¿Cuál es la diferencia entre `chmod 755` y `chmod 644`?
3. ¿Cómo ves todos los procesos activos?
4. ¿Cómo inicias un servicio de forma permanente?
5. ¿Qué es netplan?
6. ¿Cómo creas una rama en Git?
7. ¿Cuál es el puerto por defecto de SSH?
8. ¿Cómo ejecutas un contenedor Docker en background?
9. ¿Qué es un playbook en Ansible?
10. ¿Cómo listaas puertos abiertos?

---

## 💪 OPCIÓN 3: Ejercicio Integrado Completo (60 min)

**Objetivo**: Desplegar Nginx con Ansible, en Docker, desde SSH seguro

**Pasos**:
1. Configurar SSH seguro (Port, PermitRootLogin, etc)
2. Crear inventario Ansible
3. Crear playbook que despliegue Nginx en Docker
4. Ejecutar y verificar
5. Acceder desde navegador
